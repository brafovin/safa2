# Eigene Messi-Fotos

Lege deine eigenen Fotos als JPG (oder PNG) in diesen Ordner. Sie werden
vom Spiel automatisch bevorzugt, noch vor den Online-Bildern und den
SVG-Illustrationen.

## Erwartete Dateinamen

| Datei             | Motiv            |
| ----------------- | ---------------- |
| `wc2022.jpg`      | Messi mit WM-Pokal 2022 |
| `barca.jpg`       | Messi im Barça-Trikot |
| `argentina.jpg`   | Messi im Argentinien-Trikot |
| `ballon.jpg`      | Messi mit Ballon d'Or |
| `psg.jpg`         | Messi im PSG-Trikot |
| `miami.jpg`       | Messi bei Inter Miami |
| `freekick.jpg`    | Messi beim Freistoß |
| `goat.jpg`        | Portrait / GOAT-Foto |

Empfohlenes Seitenverhältnis: ca. 3:4 (Hochformat), Breite ab 400 px.
Du musst nicht alle 8 Fotos liefern – für jede fehlende Datei wird
automatisch das Online-Foto oder die SVG-Illustration angezeigt.

## Rechtliches
